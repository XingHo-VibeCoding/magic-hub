# 前端设计规则与检查清单

> 本文件分两层：**规则本体**是通用的，换项目不用改；**当前项目配置**只列具体数值，换项目只改这一节。

## 当前项目配置（换项目时只改这里）

- 品牌色：主紫 `#910782`、辅紫 `#82239A`，全部收敛在 `styles.css` 的 `:root` 变量里
- 参考站：紫光同创 pangomicro.com——Hero 大屏、扫光按钮、卡片悬停紫色浮起、导航下划线从中间展开、顶栏透明→下滑变白。**视觉基调用户明确要求不得擅改**
- 断点：960px（3列→2列）/ 720px（导航收紧）/ 620px（单列）
- 动效节奏：0.25~0.3s ease；胶囊圆角 999；测试用 jsdom 无头脚本（项目外）

## 一、页面层级

- 信息架构固定四层：顶栏 → Hero → 内容区块 → 页脚，每层只干一件事。
- 标题层级 h1→h2→h3 不跳级；版块标题用**名词短语**（"功能一览"），写"是什么"——动作交给按钮，状态交给徽标，不把排期和口语写进标题。
- 一屏一个视觉重心。**大胆只花在一处**：签名元素（如 Hero 扫光）唯一，其余部分克制——出门前照镜子，摘掉一件配饰。
- 文案是设计材料，不是装饰：主动语态；控件说清会发生什么（"保存修改"而不是"提交"）；按钮文案与结果提示**同词**（点"收藏"→提示"已收藏"）；空态与失败态说清"发生了什么 + 下一步怎么办"，不卖萌、不写内部术语（研发视角词表见项目 AGENTS.md 附注）。

## 二、颜色和字体

- **所有颜色必须走 CSS 变量**（`:root`），不得在规则里新造色值；想加新色先回答"现有变量为什么不够用"。
- 正文对比度 ≥ WCAG AA（4.5:1）；弱化文字靠色阶变量，**禁止用整体 opacity 压灰**（会把正文压到达标线以下）。
- 品牌色只用于强调（按钮 / 链接 / 焦点环 / 状态徽标），不大面积铺底；装饰性色条与主色同源。
- 字体栈与字重固定，层级靠字号与字重表达，不靠放大缩小硬凑。

## 三、卡片与按钮

- 同层级元素必须同一家族：按钮统一胶囊圆角 + 统一过渡时长；卡片统一内边距、圆角、悬停方向。
- 悬停反馈语言统一（变色 / 轻位移 / 阴影，最多取二）；**不可点的元素绝不做成按钮的样子**（用 span + 悬停提示，防假链接）。
- 新交互的反馈必须三层叠加：**状态变化**（最明确的"生效了"）+ 动效（强调）+ 提示条（说明）；提示条单实例（新的顶旧的）；**失败时必须给下一步**。
- ⚠️ 选择器特异性：新增 CSS 前先确认不会与既有类互相覆盖（尤其 `.section` 与 `.cta` 这类交叉选择器），改完用浏览器实际看一眼。

## 四、移动端适配

- 网格逐级降列（3→2→1），断点用项目配置里的既定值，不随手发明。
- 窄屏防溢出：长标题 `overflow-wrap: anywhere`；固定宽元素收紧内边距或隐藏次要文字；Toast 等悬浮元素给 `max-width`。
- 触控目标不小于约 44px；`position: fixed` 元素必须核对 z-index 层级表，不裸写魔法数字。

## 五、修改前检查（动手前逐条过）

1. 读 `:root` 与同类组件的现有样式——**优先复用，不新造**。
2. 改一处样式，先按类名扫全站，确认同类元素是否需要同步（改文案同理：**必须覆盖所有页面**，不能只改入口页）。
3. 同一文件多处编辑**串行**进行，并行编辑会互相覆盖。
4. 改文案时同步检查两处：全站研发视角词表扫描 + **测试脚本里的断言字符串**。
5. 涉及视觉基调（品牌色、Hero、动效语言）的改动：先向用户说明再动手。

## 六、修改后验证（完成后逐条过）

1. **语法**：JS 过 `node --check`；CSS 花括号配对。
2. **行为**：无头浏览器真实点击验证，不靠"看代码觉得对"。声称实现了就必须实测。
3. **回归**：既有测试全绿；边界态齐全（加载 / 空 / 错误 / 无结果）。
4. **全站**：被改类名出现的所有页面逐一核对；研发词表扫描通过。
5. **可访问性（每次必查）**：键盘 Tab 可达且 `:focus-visible` 焦点环可见；文字对比度达标；新动效被 `prefers-reduced-motion` 覆盖；动态提示带 `aria-live`。
6. **留调用记录**：何时调用本文件、按哪几条核对、发现并修了什么，写进项目调用记录文件。

## 快速检查清单

- [ ] 新颜色用了变量，没有新造色值？
- [ ] 按钮 / 卡片对齐了家族样式与动效节奏？
- [ ] 同类元素全站同步了？文案扫过词表、测试断言同步了？
- [ ] 语法 → 行为 → 回归三层验证都过了？
- [ ] 键盘焦点 / 对比度 / 减少动效 / aria-live 都查了？
- [ ] 调用记录写了？
